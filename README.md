# Зелений сигнал — тести ПДР

Безкоштовний тренажер з Правил дорожнього руху України.

- **Офіційні питання ГСЦ МВС**: усі 2332 питання з переліку за наказом № 225 від 29.10.2025, з оригінальними малюнками (1168 ілюстрацій). Для категорії B доступно 1762 питання.
- **Білет як на іспиті**: 20 питань за 20 хвилин, до 2 помилок. Склад як у сервісному центрі: 10 з ПДР, 4 з безпечного водіння, 4 за категорією, 2 з домедичної допомоги.
- **Ігри**: кросворд, пошук слів, «Знайди пару», «Хто проїде першим?», «Сортуй знаки», «Правда чи ні?», «Світлофор» (3 життя), «Бліц 60 секунд».
- На ПК це сайт, на телефоні його можна встановити як застосунок. Після встановлення він працює без інтернету.

## Файли

| Файл | Навіщо |
|---|---|
| `index.html` | Застосунок, усі питання та ігри |
| `img/p00.json` … `img/p15.json` | Малюнки до питань (пакети WebP) |
| `manifest.webmanifest` | Назва, іконки, режим «як застосунок» |
| `sw.js` | Робота без інтернету |
| `icon-*.png`, `apple-touch-icon.png` | Іконки |

## Як викласти на GitHub Pages

1. На github.com створіть новий **публічний** репозиторій, наприклад `pdr`.
2. **Add file → Upload files**, перетягніть **усі файли та папку `img`** з цього архіву → **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source **Deploy from a branch**, гілка **main**, папка **/ (root)** → **Save**.
4. За 1–2 хвилини сайт буде на `https://ВАШ-НІК.github.io/pdr/`.

Через термінал:

```bash
git init
git add .
git commit -m "Зелений сигнал: тести ПДР"
git branch -M main
git remote add origin https://github.com/ВАШ-НІК/pdr.git
git push -u origin main
```

## Як встановити на телефон

- **Android (Chrome):** меню ⋮ → «Встановити застосунок».
- **iPhone / iPad (Safari):** «Поділитися» → «На початковий екран».
- **ПК (Chrome / Edge):** значок встановлення в адресному рядку.

Щоб усі малюнки працювали без інтернету, відкрийте **Профіль → Встановити на телефон або ПК → Завантажити всі малюнки**.

Встановлення працює тільки з адреси `https://`. Якщо відкрити `index.html` просто з диска, тести й ігри працюватимуть, але малюнки до питань не завантажаться (браузер блокує читання файлів з диска).

## Оновлення

Після зміни файлів відкрийте `sw.js` і змініть `VERSION` (наприклад `zs-v2` → `zs-v3`).

## Власні питання

**Профіль → Додати власні питання**, формат JSON:

```json
[{ "q": "Текст питання", "a": ["Варіант 1", "Варіант 2"], "c": 0, "e": "Пояснення", "img": "https://..." }]
```
