# Зелений сигнал — тести ПДР

Безкоштовний тренажер з Правил дорожнього руху України: білети по 20 питань (20 хвилин, до 2 помилок), безкінечний ігровий режим, вивчення дорожніх знаків. На ПК це сайт, на телефоні його можна встановити як застосунок (Android та iOS), і він працює без інтернету.

## Що всередині

| Файл | Навіщо |
|---|---|
| `index.html` | Увесь застосунок і база питань |
| `manifest.webmanifest` | Назва, іконки, режим «як застосунок» |
| `sw.js` | Офлайн-робота (кешує сайт на телефоні) |
| `icon-*.png`, `apple-touch-icon.png` | Іконки для Android, iPhone і ПК |

## Як викласти безкоштовно на GitHub Pages (5 хвилин)

1. На github.com створіть новий репозиторій, наприклад `pdr`, тип **Public**.
2. Натисніть **Add file → Upload files** і перетягніть **усі файли з цієї папки** (не саму папку). Натисніть **Commit changes**.
3. Відкрийте **Settings → Pages**. У розділі *Build and deployment* оберіть **Source: Deploy from a branch**, гілка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 хвилини сайт буде за адресою `https://ВАШ-НІК.github.io/pdr/`.

Або через термінал:

```bash
git init
git add .
git commit -m "Зелений сигнал: тести ПДР"
git branch -M main
git remote add origin https://github.com/ВАШ-НІК/pdr.git
git push -u origin main
```

## Як встановити на телефон

- **Android (Chrome):** відкрийте сайт → меню ⋮ → «Встановити застосунок» або «Додати на головний екран».
- **iPhone / iPad (Safari):** відкрийте сайт → «Поділитися» → «На початковий екран».
- **ПК (Chrome / Edge):** значок встановлення праворуч в адресному рядку.

Встановлення можливе лише з адреси `https://` (GitHub Pages це дає). Відкритий напряму з диска файл працюватиме як звичайна сторінка, але без встановлення та офлайн-режиму.

## Як оновити сайт

Після зміни файлів відкрийте `sw.js` і змініть `VERSION` (наприклад `zs-v1` → `zs-v2`), щоб телефони підтягнули нову версію.

## Як додати більше питань

У застосунку: **Профіль → Додати власні питання** (файл або вставка JSON). Формат:

```json
[
  {
    "q": "Текст питання",
    "a": ["Варіант 1", "Варіант 2", "Варіант 3"],
    "c": 0,
    "e": "Пояснення",
    "r": "12.4",
    "img": "https://адреса-картинки.png"
  }
]
```

`c` — номер правильної відповіді, рахуючи з нуля. `e`, `r`, `img` — необов'язкові.

Щоб питання були вбудовані для всіх, додайте їх у масив `window.PDR_QUESTIONS` всередині `index.html` (там перший варіант відповіді завжди правильний, порядок перемішується автоматично).

## Прогрес

Прогрес зберігається в браузері на кожному пристрої окремо. Перенести його можна в **Профіль → Перенести прогрес** (скопіювати код на одному пристрої, вставити на іншому).
